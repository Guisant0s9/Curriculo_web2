## 📌 Sobre a atividade

Nesta atividade foi desenvolvido um **site de apresentação pessoal**, simulando o portfólio de um desenvolvedor web.

A página apresenta informações sobre o desenvolvedor, suas habilidades, projetos realizados e uma área para contato.

O objetivo foi praticar a criação e organização de uma página utilizando **HTML**, trabalhando com diferentes elementos para estruturar o conteúdo do site.

---

## 🌐 Estrutura do site

O site foi dividido em algumas partes principais:

### 👤 Sobre Mim

Nesta seção são apresentadas informações sobre o desenvolvedor, seus conhecimentos e suas principais habilidades na área de Desenvolvimento de Sistemas.

### 🚀 Meus Projetos

Foi criada uma tabela para organizar os projetos desenvolvidos.

A tabela apresenta:

* 📁 Nome do projeto;
* 🛠️ Tecnologias utilizadas;
* 📊 Status do projeto;
* 🔗 Link para visualizar o projeto.

### 📩 Entre em Contato

A parte final do site possui um formulário de contato, permitindo preencher:

* Nome;
* E-mail;
* Assunto;
* Mensagem.

Também foi adicionado um botão para enviar a mensagem.

### 📞 Rodapé

No final da página foram adicionados o ano, a instituição de ensino e informações de contato.

---

## 🛠️ Tecnologias utilizadas

* 🟠 **HTML5** — utilizado para criar a estrutura e o conteúdo da página.
* 🎨 **CSS** — apresentado entre as tecnologias utilizadas nos projetos.
* 🟨 **JavaScript** — apresentado em alguns dos projetos da página.

---

## 📚 Elementos HTML utilizados

Durante a atividade foram utilizados diversos elementos HTML, como:

* `<h1>` e `<h2>` — títulos;
* `<p>` — parágrafos;
* `<ul>` e `<li>` — listas;
* `<a>` — links;
* `<img>` — imagem;
* `<table>` — tabela de projetos;
* `<form>` — formulário;
* `<fieldset>` — agrupamento dos campos;
* `<legend>` — título do formulário;
* `<input>` — campos de preenchimento;
* `<select>` — seleção de opções;
* `<textarea>` — campo para mensagens;
* `<button>` — botão de envio;
* `<footer>` — rodapé.

---

## 🎯 Objetivo

O principal objetivo da atividade foi desenvolver uma página web estruturada utilizando HTML, simulando um **portfólio profissional de um desenvolvedor**, contendo apresentação pessoal, habilidades, projetos e formulário de contato.
